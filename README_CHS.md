# SimpleRollCall

简体中文 | [English](README.md)

一款简洁现代的 Windows 点名器（随机抽取人名）程序，基于 WPF 与 ModernWpf 构建。

## 功能特性

- **随机抽取** — 名单文本滚动 + 进度条动画
- **多人模式** — 一次抽取 1 到 10 人，以标签形式在 WrapPanel 中展示
- **两种抽取模式**
  - *手动*：名字持续滚动，按下暂停即全部立即停止
  - *自动停止*：3 秒内自动完成抽取（多人按 1→N 在 2.1s~3.0s 间渐进停止）
- **机器学习模式** — 已抽过的人进入临时记忆列表，不再重复抽取；全员抽过后清空记忆，重新开始
- **响应式界面** — 抽取文本随窗口大小缩放；单人最大 56px，多人标签最大 48px
- **主题** — 浅色 / 深色 / 跟随系统，强调色动态取自系统主题（无硬编码颜色）
- **双语界面** — 简体中文与英文，可在程序内切换（基于 .NET 资源文件的 i18n）
- **编码支持** — 名单文件支持 UTF-8 或 GB18030 编码
- **便携式** — 所有设置保存在程序同目录的 `SRC_Config.ini`；提供单文件发布版本

## 语言

程序界面支持简体中文（默认）与英文。

## 设计

- **技术栈**：.NET 8（同时提供 .NET 6 生成目标）、WPF、[ModernWpf](https://github.com/Kinnara/ModernWpf)
- **界面风格**：Fluent Design 风格的现代 UI；工具栏按钮共享随主题变化的背景矩形并以分割线隔开，对话框跟随系统强调色与明暗主题
- **布局**：三行响应式布局 —— 可缩放文本区、纤细进度条、固定高度工具栏
- **架构**：配置为纯 INI 文件（`SRC_Config.ini`）；名单为每行一个名字的纯文本文件
